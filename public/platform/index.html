Say it once. Every device answers.

scrov is a planned open-source voice agent. It turns one spoken request into WebMCP tool calls and sends them to Home Assistant, Google Cast, VITURE glasses and your desktop at the same time.

How it works

One request, fanned out.

Each stage uses an SDK that already exists. scrov is the part that connects them.

  1. Speak

    Wear a reSpeaker Clip, with two mics that pick up sound all around you up to 3 m away, or use any browser microphone.

    reSpeaker Clip · BLE 5.3 · Wi-Fi 6

  2. Understand

    A Cloudflare voice agent streams the audio over a WebSocket, transcribes it, and lets you interrupt it mid-reply. Azure Speech is the alternative speech provider.

    Cloudflare Agents · withVoice

  3. Fan out

    The agent turns the request into WebMCP tool calls and sends them in parallel to every connected device that offers a matching tool.

    WebMCP · registerTool()

  4. Confirm

    Each device returns its result. The agent answers once, out loud, with what worked and what didn’t.

    Streaming TTS

Developers

Any page you control becomes a device.

WebMCP is a proposed web standard: a page registers tools, and an agent calls them instead of clicking through the interface. scrov connects those tools to your voice.

  • Tools stay in your page. They reuse the code, session and login the page already has, so there is no second backend to build.

  • Register only what the screen can do. Abort the signal and the tool disappears from the agent’s list.

  • A bridge relays the calls. A scrov browser extension and the desktop app connect page tools to the voice agent. Planned.

  • Browser support today: origin trials in Chrome 149 and Edge 150. For local work, turn on chrome://flags/#enable-webmcp-testing.

FAQ

Questions, answered plainly.

Can I use scrov today?

Not yet. Every feature on this page is planned. Work starts with the Discord bot in scrov/bot, and the spec tracks the design as it changes.

What is WebMCP?

A proposed web standard from the W3C Web Machine Learning Community Group. A page calls document.modelContext.registerTool() to register a tool: a function with a description and a JSON schema. AI agents then call that function directly. Read the WebMCP explainer.

Which browsers support it?

Chrome 149 and Edge 150 run origin trials, and Chrome has a flag for local development. Firefox has an open standards-position discussion. The desktop app and any Firefox support depend on how this develops, and the spec lists the fallbacks.

Do I need the reSpeaker Clip?

No. Any browser microphone works. The Clip is for hands-free use all day: it clips on, picks up sound all around you, and can answer back with its screen and vibration.

Where does my voice go?

In the planned design, audio streams to a voice agent on your own Cloudflare account. The agent keeps the conversation text in its own SQLite storage, so the data stays in your account.

Which speech provider does it use?

Workers AI speech-to-text and text-to-speech by default, through the Cloudflare Agents voice API. Azure Speech is the planned alternative.
